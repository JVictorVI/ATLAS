Parâmetros de Execução do Modelo

Ajuste como o modelo será executado na sua máquina

Total de tokens que o modelo mantém por conversa, incluindo a entrada e a resposta. Valores maiores usam mais memória.
Limita o tamanho de cada resposta. Um valor maior permite respostas mais longas, mas pode aumentar o tempo de geração.
Controla a variação das respostas. Valores menores são mais previsíveis; valores maiores, mais criativos.
Limita a escolha aos tokens mais prováveis. Valores menores deixam as respostas mais focadas.
Define quantas camadas são processadas pela GPU. Mais camadas podem acelerar as respostas, mas consomem mais VRAM; 0 deixa o ajuste com a engine.
Automático (0) Calculando...
0 usa ajuste automático da engine VRAM: -
Use valores manuais apenas para ajustar desempenho ou consumo de memória. Alterações são aplicadas na próxima inicialização da engine local.
Define quantas tarefas a CPU executa em paralelo. Mais threads podem acelerar o modelo; 0 usa o ajuste automático.
Define quantos tokens são processados em conjunto. Valores maiores podem ser mais rápidos, mas usam mais memória; 0 é automático.
Divide o batch em partes processadas por vez. Valores menores reduzem o pico de memória; 0 usa o ajuste automático.
Otimização que pode reduzir o uso de memória e acelerar o modelo em engines compatíveis.
Define a precisão usada para guardar o contexto já processado. Menor precisão economiza memória, com possível perda de qualidade.
Define como o arquivo do modelo ocupa a memória. mmap reduz o carregamento inicial; mlock tenta mantê-lo na RAM.
